## 检索方法与边界

逐事件建立名称和门址查询。繁体名称转换为简体仅用于检索，原库名称保留。泛称如“住宅”“小学”优先用已记载地址；外文旧址能唯一找到同路名时，仅增加街道语境检索，不据此推定新旧门牌转换。

发现本站对带完整门牌的关键字存在漏检：例如已核全文中确有“黄浦路15号”，但相同关键字查询为零；“黄浦路”则能检出资料。因此，另对365个去重街道名逐个查询，覆盖1,962条事件的地址语境。街道命中**只代表路段语境，不能证明同一建筑或同一机构**。

普通查询跨志书检索，每项保留前5条完整返回记录，并明确标记是否还有未展开的结果。大量名称存在同名机构、异址沿革或机构成立年。**本轮全量覆盖是检索覆盖，不声称已经阅读全文中的全部命中、完成每条身份核定。** 608条“未命中”也只描述普通名称／地址查询，不代表历史上没有该机构，更不代表所有街道补充检索均无结果。

## 继续待核

`review-queue.json`保留全部2,236条输入，每条都有实际查询ID、关键字、命中数量、返回章节及摘要。已回填的9条单独标记；其余分为“检索命中但待核全文和用址”或“普通查询未命中、需换词或替代来源”，并附街道补充查询文件。不会把同名机构成立年、异址资料或街道命中自动作为地图点的年份。

例如，有利银行原记录外滩4号与现归并外滩3号的门牌问题仍未解决；同仁医院的机构创建与九江路219号使用时期仍不能混同。衡山宾馆章节说20世纪80年代才用宾馆名，未强填成1980年；兴国宾馆1号楼、西郊宾馆4号楼的专用起始年也未用其他楼栋或宾馆整体年份替代。
