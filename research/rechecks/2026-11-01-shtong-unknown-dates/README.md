# 方志数据库补年：首批有专名的建筑和机构

启动日期2026年11月1日，回填与验证日期2026年11月2日。用户指定[旧版方志数据库](https://szfz.shtong.gov.cn/difangzhi-front/book/index?oneId=1)，并选择优先查有专名的建筑和机构。

页面抓取工具无法读取该入口时，实际Chromium浏览器及该站公开全文检索服务均可用。用名称和志书范围检索，随后打开原章节全文，核对机构、门牌及年代语义；未用搜索摘要单独定年。16组名称检索返回结果，已保存16份查询响应和11篇原章节的浏览器全文及HTML。来源文件及SHA-256见`source-manifest.json`。

## 数量与实现

`inventory.json`为修改前全部年代视图中去重后的无年份时间线事件，共2247条：853名录公布时名称、1166史料记录、103建造年代、124名录原名称、1名录记录。这是事件数，不是建筑数，也不是2247幢楼没有建造年。此统计不含只有待核提示、没有建造事件的建筑。

`inventory-after-batch-001.json`为回填后同口径结果，共2236条：名录公布时名称847、史料记录1161，其余不变。减少11条，与6条名录使用沿革和5条历史记录补年对应。

`src/data/shtongDatedHistories.ts`保存本批结论。名录使用沿革按官方ID、原名、完整门牌、公布时名称共同匹配；历史记录按既有组ID、全部成员ID、原记录名和旧门牌共同匹配，并只对无年份或同一回填结论的记录生效。原始文件、建造年代、几何点位、原库链接及建筑对应关系均保留。所有来源在详情卡内可点击。

验证：43项相关回归通过，含本批13项，覆盖7条名录使用史、5条历史记录、既有年代防覆盖及重复应用。数据校验、TypeScript、生产构建通过；重启4173本地预览后，12条年代及来源链接均通过实际浏览器逐卡验证，见`artifacts/shtong-date-backfill.json`及`artifacts/shtong-court-dates.png`。
