# 地标跨源重复候选审计

本轮完成来源核对与地图显示修正：13组确认关联各合为一个可搜索地点。原始GeoJSON、建筑快照和坐标不变，保留双方史料、别名与既有现用结论。候选审计快照见 [candidates.json](candidates.json)，最终处置见下表。

## 主要发现

- 当前 29 个 VS 公园面中，Parks.dbf 有 16 条真实 IDBAT 外键、13 条占位值 200000。外键比仅按距离或拼音猜测更可靠。
- **郁氏山庄**：公园 ID 162（Yushishanzhuang）明确以 IDBAT=1566 指向 Yu Family Tomb / 郁氏山壯，地址 119 TANWEI LU、始年 1894 对应。地图点距旧面质心 109.2 米、距边界 46.2 米，坐标不应因归组而被平均或覆盖。DBF 还保留 END=1932；不得由此推断今日用途。
- **11 组已核对并新增显示归组**：半淞园、八仙桥公墓、Jessfield Park、静安寺路外国公墓、Hardoon Garden、Studley Park、南阳公园/儿童游乐场、华人公园/河浜公园、郁氏山庄、张园、外滩公园。每组有明确 park→building 源ID及用途/名称/门牌交叉。
- 法国公园、贝当公园已经完成显示归组，不再重复处理。Jessfield、Studley、Public Gardens 虽替换了旧公园面，但当前 vs-site1404/1314/500 楼点仍是独立组。
- 薤露园/宋庆龄陵园、六三园/神社、YMCA运动场/日本女子商校存在外键同址关联，但用途或时期不同，暂不自动消除标签。
- 楼表另有两组强拼写候选：**359/4135 Kelmsott/Kelmscott Garden**（188 Roi Albert），**408/4154 Dahua/Da Wha Hospital**（大华医院，19 Pottier）。两组最终地图坐标均完全相同，但一条原x/y为UTM米值，另一条为经纬度。已修正构建入口，在副本上统一投影后聚类，见 [坐标单位审计](mixed-coordinate-audit.json)。

## 保留区别

中国红十字会第三医院、上海小学幼稚园、皇后剧院、惠民小学的近邻同名项仍有不同门牌，列为待核。Shanghai Water Works 的466/484号、LOCK APARTMENTS不同门牌、树民学校甲乙校舍明确保留为不同对象。每个公园周边具名建筑全部列入空间背景，未直接当成重复。

实际采用带来源ID守卫的显示归组，汇集历史名、别名和来源记录；来源成员变化时跳过该组，避免自动扩展到未审邻居。地图使用每组原有代表几何，其他几何保留于原数据，不平均点面位置。本轮结论是地点层面的显示去重，并不裁定同一法定保护项。

## 实现与验证

- 显式对应配置：`src/data/landmarkSiteLinks.ts`；显示合并：`src/lib/landmarkSites.ts`，在既有公园替换之后执行。地图、搜索和详情共用合并结果。地点说明及原记录各有出处，来源中的年代差异并列保留。
- 公园替换补传 `sourceParkRecordIds` 及原始公园史料，保留原名称、类别与年份，避免将整理后的显示名误当原文。搜索结果改为“中文名”，避免把历史中文名误称为“今名”。
- 运行时地标从1689减到1676，1803个建筑来源ID逐个且仅一次保留；非本轮关联的地点不变，代表几何不变。原始地图仍为5507要素、3832道路；原GeoJSON、聚类JSON、建筑live快照、curated公园文件SHA256均与审计输入一致。
- 构建入口修复只在内存副本中将8条WGS84记录统一为UTM51N。1803条全量聚类试算仅新增359/4135、408/4154两组，其余1643组不变，241/242明确分离规则仍有效。本轮未运行全量`data:build`，当前页面由显式配置消除这两组重复；以后上游已合并时，若代表要素恰好包含完整且无额外的预期来源ID，仍应用规范名称与说明；不完整或新增成员组继续跳过。
- `npm test`通过149项（62前端、87脚本）；`npm run build`通过（含数据校验与TypeScript），`git diff --check`通过。
- 浏览器已确认1676处地标；搜索Yushishanzhuang、Yu Family Tomb、春光坊各仅返回同一地点，地图仅有一个Yushi Shanzhuang标签，卡片展示规范中文、关系说明及两份历史记录。
