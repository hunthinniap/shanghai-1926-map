## 输入与生成一致性

002、004 从 Git 找回的原样快照已复制到固定 `research/unresolved-landmarks/NNN-input.json`，工作流改指固定路径。003、005、006 尚未找回完整原快照，`input` 设为 null，并给出稳定 ID／旧记录上下文和追溯报告；不再指向会重新排序的 public 同号文件，也不伪造原输入。

编译回归另外发现两处先前就存在的不同步，详见 [同步计划](synchronization-plan.json)：#242 将已批准 results 的足球场结论及来源同步回旧分片，并统一同一 VS ID 的引用链接；#460 将派生路名提示与现编译器的分段提示一致，仍为 unresolved/no。二者都没有改地图、原字段或增加新研究结论。

地图待核状态存于 [持久化清单](../../../scripts/data/landmark-current-use-holds.json)。常规 enrich 和 research override 脚本都会先检查该清单，禁止人工覆盖、维基、现名推断、图书馆新查询或缓存把已撤回用途填回来。获得新证据后须先审查完整组，再调整清单；只把某条工作流改成 yes 不会解除暂停。
