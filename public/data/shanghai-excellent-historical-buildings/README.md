# 上海市优秀历史建筑名录数据

来源：[上海市房屋管理局「优秀历史建筑」目录](https://fgj.sh.gov.cn/yxlsjz/index.html)。2026-09-18 抓取目录所列第一至第五批，共 **1058 条来源记录**，保留原始网页及逐行出处，可用于后续历史地点研究。

|---|---:|---|---|
| 第一批 | 61 | 2023-06-01 | [001.json](batches/001.json) |
| 第二批 | 175 | 2023-06-01 | [002.json](batches/002.json) |
| 第三批 | 162 | 2023-06-01 | [003.json](batches/003.json) |
| 第四批 | 234 | 2023-06-01 | [004.json](batches/004.json) |
| 第五批 | 426 | 2023-05-29 | [005.json](batches/005.json) |

这些日期是页面更新时间，不代表各批批准日期，也不代表现用途核定时间。各批均为四列表格：编号、原名称／原使用单位、现名称／现使用单位、地址。页面没有独立的建造年份、经纬度或建筑轮廓字段。

## 文件

- [buildings.json](buildings.json)：全部 1058 条，位于 `records` 数组，保留来源顺序。
- [index.json](index.json)：批次、区名分布、数量及文件索引。
- [sources.json](sources.json)：来源 URL、网页更新时间、实际抓取时间、原始文件路径、字节数和 SHA-256；另登记目录中的 6 条政策／技术文件链接，未采集其正文。
- [batches/](batches/)：五批完整记录、分区、脚注、表格行统计。
- [raw/](raw/)：原始目录 HTML 和五个名单 HTML，保存响应字节，不依赖外部页面继续可用。
- [anomalies.json](anomalies.json)：原网页的重复／异常编号、缺项和控制字符。
- [validation.json](validation.json)：快照哈希、逐批计数、全部 HTML 表格行分类核对。
- [buildings-enriched.json](buildings-enriched.json)：官网1058条与维基名单逐项对应后的独立增强版，包含双方地址、建造年代、层数、结构、设计者、条目链接及有来源的坐标候选。
- [wikipedia/README.md](wikipedia/README.md)：维基采集、对应规则、来源许可、覆盖统计与复核队列；[locations.geojson](wikipedia/locations.geojson)保留原100个建筑/建筑群参考点。新增[门址坐标补查](geocoding/README.md)为原913项补入878点；合并地图共978点，其余35项本轮待核及原45项维基候选继续保留。

## 记录字段

| 字段 | 含义 |
|---|---|
| `id` | 本数据集的唯一采集标识，含同编号出现次序；不是新增官方编号 |
| `batch` | 批次，1—5 |
| `codeRaw` | 网页原编号文字，包括括号旧编号、星号、格式异常 |
| `code` | 按原文可直接识别的主编号；格式异常时为 null；**不保证唯一** |
| `alternateCodes` | 原编号括号中的其他编号 |
| `markers` | 来源编号上的星号等脚注标记 |
| `districtAsListed` | 继承该条目所在的网页分区标题，仅去除区名中的排版空白 |
| `originalNameOrUse` | 原名称／原使用单位，保留复合名称和换行 |
| `listedNameOrUse` | 来源页面记载的现名称／现使用单位，未独立核定今日用途 |
| `addressAsListed` | 来源地址，保留多门牌、范围、楼号和换行；不补全或地理编码 |
| `components` | 同一编号下合并单元格列出的子建筑，不增加名录条目计数 |
| `sourceNotes` | 与星号编号对应的灭失脚注原文 |
| `qualityFlags` | 来源异常提示，详见 anomalies.json |
| `source` | 来源元数据、表号、原表行号、分区原文和表头；表号／行号从 1 起 |
| `rawRows` | 原表单元格文本与 rowspan/colspan；HTML 原件另保存在 raw 目录 |

语义字段只整理排版空白、把 `<br>` 等保留为换行，并去除不可见控制字符；空字段为 null。`rawRows` 保留控制字符以及合并后的空续行，未经文本处理的原始内容以 HTML 快照为准。

## 已保留的来源问题

- `5A012`、`5F038` 各出现两次，代表不同原表行，四条全部保留，`id` 区分出现次序。不可按官方编号直接转为唯一键并覆盖。
- `D5035`、`50D80`、`D50102` 为原文的三个非标准编号，未擅自修成推测编号；其 `code` 为 null。
- `5D089` 地址为空；`5D095` 现名称／现使用单位为空。
- `5A049` 原名称、`5F040` 地址中存在 U+007F，原文本仍可在 `rawRows` 和原始 HTML 中查到。
- 第二批 `2B012*`、`2M009*` 和第三批 `3A020*` 分别保留“于1994年左右”“于1996年左右”“于2000年左右”灭失脚注，没有从名单删除。
- `2M006` 的六个子建筑存入 `components`，整个编号只计一条。完整单元格跨两行的空续行也不会重复计数。
- “原闸北区”“崇明县”等源分区原样保留；不能用编号字母推断今天的行政区。不同编号同址、同名记录也不合并。

异常涉及 11 条记录；9 项异常事件是因为两个重复编号事件分别涉及两条记录。

## 更新和验证

在项目根目录运行（使用现有 Node.js / jsdom 依赖）：

```sh
# 重新下载官网目录和五批网页，全部解析验证后替换本目录生成文件
npm run data:heritage

# 使用本地快照重新生成 JSON，不请求网络
npm run data:heritage -- --offline

# 只读验证：哈希、计数、逐行解析及全部 JSON 与快照一致
npm run validate:heritage
```

来源增加批次、分页变化或各批条数变化时，收集脚本会停止，要求先核对来源结构。解析器不会默默跳过无法解释的非空表格行。20 项解析回归测试覆盖合并行、脚注、别名、重复／异常编号、缺列与控制字符；独立逐行核对确认五批数量分别为 61／175／162／234／426。

可通过开发服务器读取 `/data/shanghai-excellent-historical-buildings/buildings.json`。这套名录作为独立参考数据收集，当前地图的历史坐标、分组和现用途覆盖没有改动。
