# 优秀历史建筑建造年代补查（2026-10-30）

本轮针对已经上图的978项优秀历史建筑调查并接入时间轴。原数据中571项没有可直接用于筛选的建造年代，其中466项字段缺失、105项为不详或复杂文字。本轮采用288项有来源的建造年代；尚有283项建造年代未解决，不能把整份名录说成已全部考证完成。

| 指标 | 补查前 | 补查后 |
| --- | ---: | ---: |
| 可解析的建造年代 | 407 | 695 |
| 建造年代仍不明确 | 571 | 283 |
| 时间轴年代不明的名录点 | 552 | 272 |

“时间轴年代”包括经审定为同栋建筑／构筑物的最早历史记录，故与建造年代数量不同。本次288项中8项先前已有可用历史记录，另280项从年代不明转为可按年筛选。仅开启优秀历史建筑图层时按此口径统计；双图层合计数还包含历史地标。

完整283项见[剩余待查清单](remaining-dates.md)。已逐项检查但仍保留的问题：

- 四川路桥：改建1922年与建成1923年的事件差别尚需核定，不强选一个“竣工年”。
- 四行仓库：市文旅局写1931—1935年，另有1931年说；整项名录、多个仓库与抗战纪念馆所在西部的范围尚需核对。
- 新乐路东正教堂：文旅推广网记1932—1934年，徐汇政务记1936年落成；原“1932（始建）”不当成竣工年。时间轴仍用原有同栋记录的1938年起点，不把这个资料年伪称建成年。

这些条目的原字段和来源说明见[人工核对底稿](manual-reviews.json)。下一轮应先查137项未逐项补查及31项候选；校园、医院、建筑群须具体到保护楼体，避免把机构成立或后建楼年代套给原楼。

## 文件与复现

- `raw/`：官方带年代表及4份逐项核对网页快照；中南大楼网页原编码GBK。来源元数据含原URL、发布日期、本地文件路径及SHA-256。
- `source-rows.json`：官方表按行结构化，原名称、现名、门址和年代分别保留。
- `investigation.json`：571项初始问题项，含候选、处理状态、来源、输入哈希。
- `manual-reviews.json`：7项采用、3项暂不采用的逐项核对与理由。
- `timeline-coverage.json`：采用地图真实同栋关联、去重、年代推导流程的前后对照（978项）。
- `prepare.mjs`：从本地快照生成年代覆盖数据和清单；`audit.ts`：核对时间轴覆盖。

从项目根目录运行：

```powershell
node research/supplemental/2026-10-30-heritage-construction-dates/prepare.mjs --check
node node_modules/vite-node/vite-node.mjs research/supplemental/2026-10-30-heritage-construction-dates/audit.ts --check
```

移除`--check`可重建派生文件。原始名录GeoJSON不修改，运行时仅对编号、名称、完整门址及原年代字段均相符的条目应用补录；身份发生变化会跳过，需重新核对。原字段保存在证据对象中。原坐标、名称、批次、分类和合并关系均不因补查年代改变。

验证：207项前端测试通过，生产构建通过；生成器及覆盖审计的只读检查通过。浏览器实测与本地预览记录见项目`handoff.md`。
