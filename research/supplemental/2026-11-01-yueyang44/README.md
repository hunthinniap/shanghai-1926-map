# 岳阳路44号：建造年代与使用单位分开

2026年11月1日，用户指出1968年页面中“1927年／建造年代／市文广局老干部活动中心”容易被理解为该机构1927年已经在此使用。

原因是卡片用建筑当前展示名作为建造事件标题。房管局清单确实把5D040记为“市文广局老干部活动中心”，但同一行的1927是建造年代，不能据此给机构使用史补1927。

## 可证事实

- [上海房管局带年代清单](https://fgj.sh.gov.cn/yxlsjz1/20200414/b9946bf8508e4b9689671fcd4146bb86.html)：5D040、岳阳路44号、1927。沿用既有受保护的建造年代覆盖记录；不改原始名录文件。
- [上海市文旅推广网／乐游上海](https://www1.meet-in-shanghai.net/cn/news/walking-through-1800-meters-of-wutong-streets-and-alleys-we-sought-out-the-hidden-old-villas-on-yueyang-road-and-fenyang-road-602755/)：2026-08-27文章称岳阳路44号为黄郛旧居、私人住宅。未给黄郛入住与离开日期，不能用1927建造年推算入住年。
- [魅力衡复／周到，2018-03-15](https://static.zhoudaosh.com/files/cnews/2018/20180315/0D98C8854321F9C3B52244841E13EC06694CF1C04C6653194BE51C8D18750520/2.html)：记此楼为1927年建的独立式花园住宅；1988年初《变形金刚》在上海音像资料馆地下配音室开始配音，地址岳阳路44号。该文又记其发表时由市文广局老干部活动中心使用。1988为该年使用记录；2018为报道观察年，均不等于启用或迁入年。
- [上海市文旅局直属单位介绍，2026-08-10](https://whlyj.sh.gov.cn/zsdw/20151011/0022-30139.html)：上海市文化和旅游局老干部服务中心登记地址岳阳路44号。记录同址登记，不宣称全部院落由单一单位独占，也不拿页面年份当迁入年。

## 仍待核

“1960年后音像资料馆、2005年后活动中心”的说法见个人游记，本次未找到可靠原始依据，未据此填具体沿革年份。1968年的使用单位继续留空。研究者关于旧42号与今44号、多个先后住户的讨论未完成原始行号录逐年核对，未导入门牌转换或住户年代。
