## 采用和保留原则

只采用“居住、寓居、入住、住所、旧居”等能确认实际住宅或住宿关系的具名资料；设计、产权、办公、就学、来访及纪念命名不自动等于居住。旅馆短期下榻另作注明。住户时间只取明确居住记载，不用建成年、列保年、出生或去世年份补入住时间。先后不同门牌分开保留，缺年不伪造年份；常德公寓等条目内的迁出年份矛盾不强选。

主队列25篇范围问题保留在复核清单，包括同名异地的苏州严家花园、相邻但不等同的永嘉路501号与岳阳路145号、哈同花园居民与后建展览中心。已拆旧居和重建住宅的沿革明确注明，仅在原址范围清楚时采用。丰阳馆住客无法逐人对应不同时期馆址，本轮不套到现地图楼体。

汤山村维基写包玉刚“1949年后”居住，与长宁华阳2020年原报道不一致。核读[原报道](https://www.thepaper.cn/newsDetail_forward_8846594)后采用1945—1948年，保留维基和校正来源两条链接及冲突说明；HTML、SHA-256和支持内容见`supplemental-sources.json`。李白的条目明确是革命烈士，姓名旁备注其身份。蒋中正统一显示为常用名蒋介石，复核档保留来源原名。

## 可复核性和前端接入

`queue.json`冻结来源词条和ID／原名／完整门址；`raw/`保留全文API响应，`manifest.json`保存哈希、版本和请求元数据。每条前端维基依据链接到本次核读的固定版本。全文采集细节、引用清洗修复及许可见[collection.md](collection.md)。

`compile.mjs`核对全部页面结果、原文哈希、名录身份、来源词条对应、姓名确在原文出现、维基版本一致，再从人工审定结果生成`src/data/wikipediaNotableResidents.json`、汇总和已采用表。只有人工判定能决定居住关系，关键词或姓名出现本身不能自动采用。

`notableResidents.ts`按名录ID、原名与完整地址守卫，接入所有地点卡；已有逸村和岳阳路44号记录保留。新增住户姓名也进入搜索。没有更改原始名录、坐标、道路、楼栋关联或建筑生灭日期。

```powershell
node --preserve-symlinks --preserve-symlinks-main research/supplemental/2026-11-02-wikipedia-residents/collect.mjs --check
node --preserve-symlinks --preserve-symlinks-main research/supplemental/2026-11-02-wikipedia-residents/compile.mjs --check
```

验证包含全部68项身份／门牌守卫、每条来源固定版本、卡片居民分区、姓名搜索，以及访客和邻址不误归属。前端272项和Node93项测试通过。维基文字依CC BY-SA 4.0，原条目、版本和归属链接保留。

生产构建通过，本地4173服务已使用新构建。`artifacts/wikipedia-residents-audit.json`核验1044张名录卡片实际生成70张有居民分区、182条记录，其中51条带有来源记载的时间；其余只显示姓名、门牌和依据，不补造年份。
