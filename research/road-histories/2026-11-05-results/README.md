# 2026-11-05 道路调查资料回填

2026-11-06 用户提供 Downloads 下的 `2026-11-05-road-histories-results`，要求回填道路数据。34 个 JSON 原文件逐字节归档于 [input](input/)，哈希见 [input-manifest.json](input-manifest.json)。文件内容作为调查资料读取，没有把其中的检索说明当作执行指令。

同日用户进一步明确：提供资料中清楚的道路事件可直接进入主时间线，区间取最早年。例如江宁路显示“1884年戈登路、1943年江宁路”。未再次核读原文或输入标记为conflicting本身不再构成拦截理由。此口径取代首轮仅采用55组的限制，见 [adoption-policy.json](adoption-policy.json)。

## 接入范围与状态

- 33 批、638 个道路组，汇总文件与各批文件内容完全一致，ID 无重复。每组的 `featureGroupId`、`historicalName`、`modernNameZh` 均与当前地图精确匹配。
- 提供方标注为 577 verified、56 conflicting、5 unresolved。这是输入资料的状态，不等于本项目独立核实了 577 组。
- 本批采用 **563个道路组、519条现代道路的1097条事件、60条名称来源**。其中57组按已有维基固定版本整理，506组按用户确认的资料采用口径整理；后者没有声称重新打开了所有外部原文。核读决定见 [review-decisions.json](review-decisions.json)，逐组采用依据见 [integration-audit.json](integration-audit.json)。
- 原有10个道路组、9条现代道路的审定沿革保持优先。目前主时间线合计573个道路组、528条现代道路。
- **638组原提供资料全部保留在“补充沿革资料（含待核内容）”**，默认折叠、展开时按批读取。保留原始区间、身份说明、事件及路段、名称来源、引用和差异说明。另75组暂未进入主时间线：16组名称占位或身份未明、6组主支路或原名错配、53组仅有建筑门牌或片段文字、尚无可用名称事件。
- 逐组采用情况和待核原因见 [integration-audit.json](integration-audit.json)。没有改写原始 GeoJSON、道路几何、名称、分组、年份筛选规则或地铁设置。

## 实际发现并处理的问题

| 问题 | 处理 |
| --- | --- |
| 江宁路1884—1900年区间、1909年巡捕房、1943年更名 | 主时间线显示1884戈登路、1943江宁路；原区间和巡捕房事项留在展开资料中 |
| 高安路把高安公寓、西湖公寓、少年宫等建筑或机构年代混成道路事件 | 采用可用的1914年道路事件，单独剔除建筑／机构年代，不因此暂缓整个道路组 |
| 威海路将“全长1740米”抽成1740年 | 主时间线只采用1901年始建、1966年更名；原记录保留供核对 |
| 安义路把“1949年后”收窄为1949年 | 使用原时间范围，无精确 year；1915年是当时已有的路名，不称辟筑 |
| 五原路把主教任期混入道路命名，部分年代有范围限定 | 五原路保留“1925年以前”；余庆路主时间线按1920显示，原“1920年代初”保留在底稿和说明中 |
| 淡水路两条原名记录对1943年的表述不一致 | 采用固定版本正文：1943南通路、1946英士路、1950恢复淡水路；更早的淡水路名不强补年份 |
| 建国东路存在1945／1946更名异说 | 保留“1945年（一说1946年）”，不强定唯一年 |
| 合肥路、兴业路、建国西路的分段修建 | 显示具体路段；不把东段或西段年份套作全路建成 |
| 瑞金二路只有1943年收回租界背景，未明确现名更名年 | 采用1907辟筑、1914辖区调整，不据背景补现名日期 |
| 原数据现代名含 TO DO、UNNAMED、VANISHED、XX | 保留原始身份字段和待核说明，不替换为资料中推测的新名称 |
| 大量以建筑门牌、地图收录或通用命名规则支持的事件 | 保留为线索，不自动认定筑路或改名年份 |
| 单条事件内列出两个带年名称，如1945林森西路→1950淮海西路 | 拆成各自有年的名称阶段，不把两个名称都放在区间起年 |
| 淮海中路原事件混入西路段1925年辟筑、1930年代陆家路 | 根据固定版本正文，分别采用1900西江路、1906宝昌路、1915霞飞路、1943泰山路、1945林森中路、1950淮海中路 |
| “1943年改回西藏路”曾被误提取为“回西藏路” | 完整识别“改回”等动词，两条原名记录均显示“西藏路”，来源链接保留；同时检查改称为、恢复为、复名为，保留真实路名中的“回” |

安福路主时间线按1914年显示，原1914—1915年及民国纪年换算问题保留于资料中。重庆中路正文1901年／信息框1889年、建国西路东段正文1912年／信息框1907年的差异仍保留说明。“以前／之后”和“一说”等没有明确区间起点的表述继续保留原限定。

## 离线重现

```bash
npm run data:road-histories
npm run validate:road-histories
```

编译器校验原件哈希、各批与汇总一致性、道路三字段身份、来源 URL 协议、所核原文和快照版本，生成：

- `src/data/importedRoadHistories.json`：563组主时间线和名称来源。保留采用依据及原始区间；定向核读记录的区间显示年由`displayYear`单列，避免改掉原period。
- `src/data/roadHistorySupplementIndex.json` 与 `public/data/road-history-supplements/01.json` 至 `33.json`：补充资料索引与按需读取内容。
- 本目录的 `integration-audit.json`：逐组状态及采用统计。

未运行`data:build`，也不需要道路对齐。`scripts/lib/road-history-import.mjs`只整理道路名称阶段，剔除建筑／机构、长度、地图资料年和路面工程；每组被剔除的原事件索引及理由均在审计中保留。下一步可优先补75组缺失的名称事件或身份对应，已有可用记录无需再因缺少本轮外部核读而暂停展示。
