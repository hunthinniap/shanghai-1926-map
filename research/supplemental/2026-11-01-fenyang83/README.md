# 毕勋路83号：1927年波兰公使代办处与后续医院院址

核读日期：2026年11月1日。用户要求将VS413“波蘭公使館及總領事館／Embassy of Poland”的未知年份补为1927年，并补后续眼耳鼻喉科医院阶段。

用户进一步追问原库“上海ュタセ醫院”的含义及中间阶段，见[犹太医院追加核读](jewish-hospital-followup.md)：新找到乔争月报道转述波兰外交使团撤出、犹太社区租用办医院的衔接，并核出两部方志1942／1943迁入年份差异；异常假名的原始底图仍未核读。

- **1927年**：[上海通志·外国驻沪使领馆·波兰领馆](https://szfz.shtong.gov.cn/difangzhi-front/book/detailNew?bookId=2247&nodeId=103622&oneId=1&parentNodeId=79302&type=-1)明确记波兰政府在毕勋路（今汾阳路）83号设公使代办处。1929年重设总领事馆及后来迁太原路126号是另外的机构沿革，不能把总领事馆其后的全部历史留在83号。1927为此址使用史的有据年份，不是建筑建成年份。
- **1952年7月1日**：[复旦大学医学宣传部《何章岑：谦谦学者，温润如玉》](https://news.fudan.edu.cn/2023/0727/c242a135823/page.htm)记医院成立、眼科团队搬至汾阳路83号。医院[党委宣传部院史文章](https://www.cn-healthcare.com/articlewm/20230130/content-1503753.html)亦记建院日，并说明期间数次更名。因此医院阶段取1952，不把1949概括年代当作建院日期。
- **2001年**：上述医院自身文章明确说更为现名。后续[复旦上医院史馆介绍](https://shmc.fudan.edu.cn/2023/1201/c2658a138331/page.htm)直接确认汾阳院区为汾阳路83号。

范围限制：[复旦大学《汾阳路83号10号楼》](https://www.fudan.edu.cn/2019/0424/c426a95979/page.htm)将今10号楼记为1942年三德堂及教堂，并说1952年底医院接手该楼。这不能独自证明1927年的波兰馆就是今天10号楼。原地图中VS413及VS1716已经同组；本次只为该既有院址补史，保留两个原始ID、门牌、点位与各自记录，没有新增与4D009犹太医院、水塔的同楼合并。

实现：`src/data/fenyang83History.ts`按现有组ID、成员413／1716、413名称及旧门牌校验，只给413补1927观察年与方志证据；1942年VS1716记录保留。1927使用`startYear=endYear`，不伪称从此无限期使用。医院阶段按`site-use`呈现：1952—2001为眼耳鼻喉科医院院址，2001起显示现名及汾阳院区地址。

`HistoricalRecord.dateEvidence`保存补年来源及语义，卡片中年份记录链接到该方志，原VS来源仍在收录和来源列表。`HistoricalSitePhase.address`让有来源的院址随阶段显示，未改建筑生灭字段。时间轴在1927、1942、1952、2001及当前分别按对应史料／阶段显示。

来源：`sources/`包括方志浏览器核读记录与渲染DOM、复旦大学及医院公开HTML原件和获取元数据；`source-manifest.json`含10份文件的字节数和SHA-256。浏览器截图与核验：`artifacts/fenyang83-history.png`、`artifacts/fenyang83-history.json`。
