TitlePublic Parks in Shanghai before and after 1949
AuthorsChristian Henriot - Isabelle Durand (GIS specialist)
Year1949
Resource ProviderChristian Henriot
Description

This shape file contain a set of 46 public parks located in Shanghai in the late Qing and Republican era. This also includes parks created after 1949 up to 2007.

The attribute table contains the following major fields:

 

Field name Description
IDBAT Identifier of the digital object (building)
ID_PARKOBJ Identifier of the park (Virtual Shanghai)
F_ADDRESS Full address of the park
START Date of opening
END Date of destruction
DIGITSOURC Source of the data
GEOMETRY Type pf geometry
TODAY Indicates whether the park still exists (Yes) or has disappeared (No)
ID_ENTITY Identifier
NAMEGUIDEJ Name in Makoto Kinouchi 木之内誠. Shanhai gaido mappu 上海歴史ガイドマップ. Tokyo 東京: Zōho kaiteiban 大修館書店, 2011.
CURRENT_NA Current name in pinyin
S_NAME Name of the park in English or French before 1949
